Tech Stack

AWS underneath, Databricks on top

source

Amazon RDS for MySQL

Binlog-enabled OLTP source, custom DB parameter group.

CDC

Debezium

Self-managed Kafka Connect worker on ECS/Fargate, private subnet.

streaming

Amazon MSK

Managed Kafka — durable CDC event log, topic per table.

observability

AKHQ

Kafka UI on ECS/Fargate for browsing topics and connector status.

storage

Amazon S3 + Delta Lake

ACID table storage, time travel, schema evolution.

catalog

Unity Catalog

Table metadata, grants, automatic lineage — no separate service.

ingestion

Databricks Structured Streaming

Kafka → Bronze Delta, trigger(availableNow=True).

transform

dbt-databricks

Bronze (ephemeral) → Silver (incremental merge) → Gold (table).

compute

SQL Warehouse

Interactive SQL + dbt execution engine.

orchestration

Databricks Workflows
