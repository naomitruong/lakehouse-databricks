Medallion Layers

One Unity Catalog, three schemas, clear contracts

bronze

Raw CDC, append-only

Every Debezium event exactly as it arrived — never mutated, never deleted in place.

  • Written by Structured Streaming from MSK
  • trigger(availableNow=True) + real checkpoints
  • Full change history for time travel
lakehouse.bronze.orders · lakehouse.bronze.customers
silver

Deduped current state

Latest row per key via ROW_NUMBER(), deletes removed, types conformed.

  • dbt incremental models, merge strategy
  • dbt tests gate promotion to Gold
lakehouse.silver.orders_silver · lakehouse.silver.customers_silver
gold

Business-ready star schema

Facts and aggregates the SQL Warehouse and BI tools query directly.

  • dbt table models, rebuilt each run
  • Serves Tableau / Looker / Power BI
lakehouse.gold.fact_orders · lakehouse.gold.agg_daily_revenue

Quick Start

From empty account to data in Gold

01

Provision the infrastructure

Terraform stands up VPC, RDS MySQL, MSK, S3, Secrets Manager, ECS services for Debezium + AKHQ, and the Databricks side (Unity Catalog, SQL Warehouse, cluster policy).

# fill in secrets first
cp terraform/terraform.tfvars.example terraform/terraform.tfvars
cp .env.example .env

make tf-init
make tf-plan
make tf-apply
02

Bootstrap the CDC source

Creates source_db, the demo tables, and the replication user with binlog privileges.

mysql -h $(terraform -chdir=terraform output -raw mysql_endpoint) \
  -u pipeline_admin -p source_db < scripts/init_mysql_cdc.sql
03

Register the Debezium connector

Posts debezium/connectors/mysql-source.json to the Kafka Connect worker; topics cdc.source_db.* start filling.

make register-debezium
04

Deploy the Databricks Workflows

The Asset Bundle deploys both jobs as code — no Airflow, no DAG files.

databricks configure   # or export DATABRICKS_HOST / DATABRICKS_TOKEN
make bundle-deploy
05

Run the pipeline

Both jobs are on a 3-hour cron; trigger them manually to skip the wait, then query Gold from a SQL editor.

make bundle-run-bronze   # MSK → Bronze
make bundle-run          # dbt: Bronze → Silver → Gold

SELECT * FROM lakehouse.gold.agg_daily_revenue ORDER BY order_date_day DESC;

Demo Scenarios

Seven things this pipeline can show you

Demo 1

End-to-end CDC flow

Insert a row into MySQL, watch it land on MSK, then in Bronze, then in gold.fact_orders — about five minutes.

Demo 2

Delta time travel

VERSION AS OF / TIMESTAMP AS OF and DESCRIBE HISTORY on the append-only Bronze table.

Demo 3

Schema evolution

ADD COLUMN with zero downtime and no file rewrite; old rows simply read back NULL.

Demo 4

Partition evolution

Repartition a live table and keep querying it — Delta's answer to Iceberg partition evolution.

Demo 5

Federation query

Join Delta Gold tables against the live RDS source through a Lakehouse Federation foreign catalog — no copy required.

Demo 6

Lineage & docs

Unity Catalog table/column lineage comes for free; dbt docs adds the model-level DAG.

Demo 7

Data quality gates

A failing dbt test stops the workflow before Gold is rebuilt — the layer boundary is enforced by the orchestrator.
